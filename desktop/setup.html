Connect your TMDB account

Posters, details, cast and episode lists come from TMDB (The Movie Database). It needs your own free key — you only do this once.

  1. Open the and sign in (or create a free account).
  2. Copy either the API Key or the API Read Access Token — both work.
  3. Paste it below and press Connect.

Your key is stored encrypted on this PC only. You can change it any time in Settings.
